# LH Games

Projeto desenvolvido utilizando HTML5, CSS3, Bootstrap 5, JavaScript e jQuery.

## 📌 Sobre o Projeto

O site simula uma loja de games chamada **LH Games**, contendo:

- Página inicial com carrossel de banners  
- Seção de produtos mais vendidos  
- Página de login  
- Formulário de cadastro com exibição dinâmica  
- Botão "Voltar ao topo" com efeito suave  
- Layout responsivo para desktop e mobile  

## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3  
- Bootstrap 5  
- JavaScript  
- jQuery
