## 📌 Sobre o Projeto

O site **LH Games** simula uma loja de games voltada ao público gamer, com foco em experiência de compra e navegação intuitiva.

Funcionalidades principais:

- Página inicial (`index.html`) com carrossel de banners  
- Seção de **produtos mais vendidos**  
- Página de **login**  
- **Formulário de cadastro** com exibição dinâmica (jQuery)  
- Botão **"Voltar ao topo"** com efeito de scroll suave  
- Layout responsivo para desktop e mobile (Bootstrap 5)

## 🛠️ Tecnologias Utilizadas

- **HTML5** – estruturação da página  
- **CSS3** – estilização e animações básicas  
- **Bootstrap 5** – layout responsivo e componentes  
- **JavaScript** – interatividade e validação dos formulários  
- **jQuery** – manipulação de DOM e exibição dinâmica do formulário de cadastro  

---

## ⚙️ Funcionalidades Implementadas

- **Validação simples de login** (verificação de campos preenchidos)  
- **Validação simples de cadastro** (email, tamanho mínimo de senha, etc.)  
- **Exibição dinâmica do formulário de cadastro** (aparece/esconde com jQuery)  
- **Scroll suave para o topo** com botão “Voltar ao topo”  
- **Layout responsivo** com Bootstrap (grid e classes responsivas)  
- **Carrossel de banners** na página inicial  
- **Formulários de login e cadastro** com estilos consistentes
